Issues I've identified in the extracted data display

Here's what I found from the code — click each one to confirm or tell me I'm wrong

1

GeoJSON displayed as raw JSON text

The displayValue function does JSON.stringify() for objects. Should show a mini map preview instead of raw text blob.

2

Scientific name asked when it's deductible

"Raw Cocoa Beans" → "Theobroma cacao". The extraction schema doesn't include scientificName at all, and there's no lookup table. Should auto-fill from commodity name.

3

Fields shown in UI that don't exist in data

region, latitude, longitude, supplierEmail are in the UI field groups but aren't in the extraction schema or merge pipeline. They'll always show "—".

4

Country code "CI" instead of full name

Country stored as "CI" but should display "Côte d'Ivoire". Need a reverse lookup for display.

5

UI is ugly & duplicate heading

"Données extraites" heading appears twice (in ShipmentDetailPanel AND ExtractedDataGrid). Overall styling needs polish — tighter spacing, better visual hierarchy.

6

GeoJSON blob is too big / unstyled

The raw JSON string for GeoJSON has no truncation, no formatting, no map. Just an eye-sore JSON blob in a data row.

# Pricing — Antaios

Antaios is an all-inclusive EUDR compliance platform for importers. Flat-rate pricing, no per-shipment fees.

## Pro
- Price: €500/month or €5,000/year (2 months free)
- Unlimited shipments and users
- Automated document data extraction (PDF, CSV, Excel, GeoJSON, images)
- Due Diligence Statement (DDS) generation
- Global Forest Watch deforestation scanning
- TRACES system submission
- Risk assessment PDF generation
- Supplier data management via supplier portal
- Email + chat support
- Free diagnostic tool (no account required)

## Enterprise
- Price: Custom
- Custom integrations via API access
- SLA and dedicated support
- Multi-org management
- Priority feature development

## Compared to alternatives
- Consulting firms: €5,000–€20,000 per engagement
- Enterprise SaaS platforms: €15,000+/year
- Antaios: €6,000/year (annual plan)
